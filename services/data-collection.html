HOW I WORK

From source identification to a dataset you can actually use.

01
DEFINE THE SOURCE

Start with the information, not the tool.

Identify what data is needed, where it can be obtained and how frequently it needs to be collected.

02
COLLECT THE DATA

Build the appropriate extraction workflow.

Use APIs, web extraction, file ingestion or a combination of methods depending on the available sources.

03
VALIDATE & STRUCTURE

Make sure the output is usable.

Check expected fields, formats and completeness while organising the collected information into a consistent structure.

04
DELIVER THE OUTPUT

From dataset to reusable process.

Deliver the resulting data in an appropriate format or package the collection logic into a workflow that can be run again.
